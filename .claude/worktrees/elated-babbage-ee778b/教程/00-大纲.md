# 全栈开发 + 大模型应用 完整学习教程

> 以 llm-live2d 项目为主线，从零开始学会全栈开发

---

## 这套教程能让你学到什么

学完这套教程，你将能够：

- 独立编写 Python 后端（FastAPI）
- 独立编写 HTML/CSS/JavaScript 前端
- 理解前后端如何通过 HTTP 和 WebSocket 通信
- 调用大模型 API（OpenAI / DeepSeek / 任意兼容接口）
- 实现流式输出（打字机效果）
- 集成语音合成（TTS）
- 驱动 Live2D 模型做出表情和动作
- 用数据库实现用户注册/登录
- 用 Session 隔离多用户对话历史
- 将项目部署到真实服务器并上线

## 全栈开发知识地图

```
全栈开发
├── 前端（用户看到的界面）
│   ├── HTML —— 网页的骨架（内容）
│   ├── CSS  —— 网页的皮肤（样式）
│   └── JavaScript —— 网页的肌肉（交互）
│       ├── DOM 操作（改变页面内容）
│       ├── 事件处理（点击/输入等）
│       ├── fetch / XMLHttpRequest（发请求）
│       └── WebSocket（实时双向通信）
│
├── 后端（服务器上跑的程序）
│   ├── Python + FastAPI —— 处理请求、业务逻辑
│   ├── HTTP 协议 —— 前后端通信的基础
│   ├── WebSocket 协议 —— 实时通信
│   ├── 异步编程（async/await）—— 高并发基础
│   └── 环境变量 / 配置管理
│
├── 数据库（存数据）
│   ├── SQLite —— 本地开发，零配置
│   └── PostgreSQL —— 生产环境
│       ├── SQL 基础（增删改查）
│       └── SQLAlchemy ORM（Python 操作数据库）
│
├── 大模型相关
│   ├── OpenAI API 格式（业界标准）
│   ├── 流式响应（Server-Sent Events / WebSocket）
│   ├── Prompt 设计（系统提示词）
│   ├── 对话历史管理（messages 列表）
│   └── TTS（文字转语音）
│
└── 部署
    ├── Linux 服务器基础命令
    ├── Nginx 反向代理
    ├── HTTPS 证书（Let's Encrypt）
    └── 进程管理（systemd / supervisor）
```

## 学习路线建议

### 路线 A：完全零基础（推荐按章节顺序）

```
第1章 → 第2章 → 第3章 → 第4章 → 第5章（部署！）
→ 第6章 → 第7章 → 第8章 → 第9章 → 第10章 → 第11章 → 第12章 → 第13章
```

每章预计时间：2～8 小时，全程约 2～3 周。

### 路线 B：有一点 Python 基础

可以快速过第 1-3 章，重点在第 4 章之后。第 5 章的部署不要跳过。

### 路线 C：只想快速看到效果

先跑第 4 章（最小可行版本），有了成就感再做第 5 章部署，然后继续往后。

## 项目演进路线图

我们将分阶段构建同一个项目，每一阶段都是可以运行的完整版本：

```

阶段 1：最小聊天（第 4 章）

  └─ 真正的 AI 回复（但要等全部生成完再显示）

阶段 5：语音 + Live2D（第 8-10 章）
  └─ AI 说话 + 虚拟形象动起来

阶段 6：多用户（第 11-12 章）
  └─ 登录注册，每人独立对话

阶段 7：摄像头眼球跟随（第 13 章）
```
