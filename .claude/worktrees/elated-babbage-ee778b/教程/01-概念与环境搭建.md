# 第 1 章：概念与环境搭建

> 在动手写任何代码之前，先搞清楚我们要做什么、用什么做——工具装好，方向对了，后面才不会迷路。

---

## 1.1 全栈开发是什么

你打开微信，发一条消息。这条消息怎么到对方手里的？

背后的路径大概是这样的：你的手机屏幕（前端）把你的文字打包，通过网络发给腾讯的服务器（后端），服务器把消息存起来（数据库），再推送给对方。对方的手机屏幕（前端）收到推送，显示出来。

**前端**：运行在用户设备上的代码，负责用户看到的界面和交互。我们用 HTML/CSS/JavaScript 写。

**后端**：运行在服务器上的代码，负责处理数据、执行业务逻辑、和数据库打交道。我们用 Python 写。

**全栈开发者**：前后端都能写的人。这套教程结束之后，你就是了。

一个更直观的比方：前端是餐厅的大堂和服务员（用户能看到摸到的一切），后端是厨房（真正做菜的地方），数据库是冰箱（存食材）。用户只跟大堂打交道，完全不需要知道厨房里在发生什么——这就是前后端分离的意义。

---

## 1.2 我们会用到的技术，以及为什么

这个项目里会出现这些技术：

**HTML/CSS/JavaScript**：前端的三件套。HTML 搭骨架，CSS 化妆，JavaScript 让它动起来。三者缺一不可。

**Python + FastAPI**：我们的后端语言和框架。Python 语法简洁，FastAPI 是目前 Python 生态里最现代的 Web 框架，写起来非常舒服，还自带接口文档——调试的时候你会爱上它的。

**WebSocket**：一种比 HTTP 更"实时"的通信协议，用来做打字机效果的流式输出。第 7 章才会用到，现在只需要知道它的存在。

**SQLite / PostgreSQL**：数据库。本地开发用 SQLite（一个文件，零配置），上线之后换 PostgreSQL（更稳健）。

**OpenAI 格式的大模型 API**：市面上大多数 LLM 服务（DeepSeek、通义千问等）都兼容 OpenAI 的接口格式，学会了一个，其余的都会。

看起来很多，但我们是一章一章来的。这章只需要把工具装好，跑起来两个 Hello World。

## 1.3 装好 Python

Python 是我们后端的语言。去 [python.org/downloads](https://www.python.org/downloads/) 下载 **Python 3.11 或 3.12**。

Windows 用户装的时候有一个关键步骤：安装界面最下面有一个复选框，**"Add Python to PATH"，一定要勾上**。这个选项的意思是让你的系统知道 Python 装在哪里，不勾的话以后在命令行里找不到它。

装好之后，打开命令提示符（Windows 按 Win+R，输入 cmd 回车），试一下：

```
python --version
```

如果看到 `Python 3.11.x` 这样的输出，就装好了。

macOS 用户推荐用 Homebrew 安装：`brew install python@3.12`，装完之后用 `python3 --version` 验证。

> **试一下**：打开你的命令行，运行 `python --version`（Windows）或 `python3 --version`（Mac），确认版本号正确。这是后面所有工作的基础。

## 1.4 装好代码编辑器

推荐用 **VS Code**——免费、插件丰富、前后端代码都好用。去 [code.visualstudio.com](https://code.visualstudio.com/) 下载。

装好之后，打开 VS Code，点左侧的插件图标（四个方块的那个），搜索并安装：
- **Python**（微软官方的，必装）
- **Prettier - Code formatter**（代码格式化，选装）

然后新建一个文件夹，就叫 `my-live2d`，用 VS Code 打开它（文件 → 打开文件夹）。这就是我们整个项目的根目录，后面所有文件都在这里。

---

## 1.5 虚拟环境：给项目一个独立的包空间

在装后端依赖之前，先来解释一件事——为什么要用虚拟环境。

你可能以后会同时开几个 Python 项目。项目 A 需要 fastapi 0.100，项目 B 需要 fastapi 0.110，如果都装在系统里，两个版本会打架。虚拟环境的作用就是给每个项目一个独立的"包空间"，互不干扰。

在 VS Code 里打开终端（快捷键 Ctrl+`），进入你的项目文件夹，然后：

```bash
# 创建虚拟环境，名字叫 venv
python -m venv venv

# 激活虚拟环境
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate
```

激活成功后，命令行最前面会出现 `(venv)` 字样。**以后每次打开项目，都要先激活虚拟环境**，这是个好习惯。

---

## 1.6 安装后端依赖

虚拟环境激活之后，安装这几个包：

```bash
pip install fastapi uvicorn httpx aiofiles
```

- **fastapi**：后端框架，我们写 API 用它
- **uvicorn**：运行 FastAPI 的服务器
- **httpx**：异步 HTTP 客户端，之后调用大模型 API 会用到
- **aiofiles**：让 FastAPI 能提供静态文件（HTML/CSS/JS）

装好之后，跑一下验证：

```bash
python -c "import fastapi; print('FastAPI 版本：', fastapi.__version__)"
```

看到版本号输出就没问题了。

## 1.7 Hello World：第一个网页

在 `my-live2d` 里新建文件夹 `frontend`，在里面创建 `index.html`。

这个文件只需要几行，作用是：告诉浏览器"这是一个 HTML5 文档"，设置标题，显示一段文字。用浏览器直接打开这个文件，就能看到页面。

> **试一下**：创建 `frontend/index.html`，写一个最基本的 HTML 骨架——`<!DOCTYPE html>`、`<html>`、`<head>`（放标题）、`<body>`（放内容）。在 `<body>` 里随便写几个字，然后双击文件用浏览器打开，确认能看到你写的内容。

---

## 1.8 Hello World：第一个后端

在 `my-live2d` 里新建文件夹 `backend`，在里面创建 `main.py`。

FastAPI 的最基本结构就三步：导入 FastAPI，创建一个 `app` 实例，用装饰器 `@app.get("/")` 定义一个路由函数。路由函数返回什么，浏览器就收到什么（FastAPI 会自动把字典转成 JSON）。

在终端里进入 `backend` 文件夹，启动服务：

```bash
uvicorn main:app --reload
```

这里 `main` 是文件名，`app` 是你创建的 FastAPI 实例变量名，`--reload` 是说"代码改了就自动重启，不用我每次手动停再开"。

打开浏览器，访问 `http://127.0.0.1:8000`，看到 JSON 响应，后端就跑起来了。

> **试一下**：再访问 `http://127.0.0.1:8000/docs`。这是 FastAPI 自动生成的接口文档页面，不需要你写一行额外代码。里面列出了你定义的所有路由，可以直接在页面上测试。以后每次写完新接口，都可以来这里验证。

## 1.9 理解 HTTP：前后端通信的语言

前端发请求、后端回响应，这套规则叫 **HTTP 协议**。

每个 HTTP 请求都有一个**方法**，说明意图：
- **GET**：我要拿数据（不改变服务器状态）
- **POST**：我要提交数据（发消息、登录、创建资源）
- **PUT / DELETE**：更新或删除

响应有一个**状态码**：
- **200**：成功
- **404**：找不到你要的东西
- **422**：你发来的数据格式不对
- **500**：服务器自己出错了

> **你可能会问**：为什么要区分 GET 和 POST，直接用一种不行吗？
>
> 可以强行用一种，但会很别扭。GET 请求的参数直接暴露在 URL 里（`/search?keyword=你好`），适合查询；POST 把数据放在请求体里，适合提交敏感信息和大量数据。遵守这个约定，代码的意图会更清晰，别人接手也更好懂。

## 1.10 此刻你的项目长什么样

```
my-live2d/
├── venv/                    ← 虚拟环境（不要手动改）
├── backend/
│   └── main.py              ← 第一个后端 ✓
└── frontend/
    └── index.html           ← 第一个网页 ✓
```

两个 Hello World 都跑起来了，但它们还是各自独立的——前端不认识后端，后端不知道前端。从下一章开始，我们把前端做得好看一点，第三章做好后端，第四章把它们联起来。

---

## 本章小结

- **前端**跑在浏览器，**后端**跑在服务器，两者用 **HTTP 协议**通信
- 虚拟环境给每个项目独立的包空间，每次开工先激活 `(venv)`
- FastAPI 用 `@app.get` / `@app.post` 定义路由，自带 `/docs` 接口文档
- HTTP 方法（GET/POST）和状态码（200/404/500）是通信的基本语言

## 常见问题

**`python` 命令找不到**：Windows 安装时没有勾选"Add Python to PATH"，重新安装时记得勾上。

**`uvicorn` 命令找不到**：虚拟环境没有激活——看命令行前面有没有 `(venv)`，没有的话先激活。

**端口被占用**：换一个端口 `uvicorn main:app --reload --port 8001`。
