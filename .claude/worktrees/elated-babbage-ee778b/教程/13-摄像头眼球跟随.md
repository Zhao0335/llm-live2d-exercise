# 第 13 章：摄像头眼球跟随

> 这章实现一个有点"黑科技"感的功能：摄像头对着你，Live2D 的眼睛就盯着你看。不只是头部转向，而是眼球本身跟着你的脸动。

---

## 13.1 为什么说这是"真正的眼球跟随"

之前我们用了 `model.focus(x, y)` 让 Live2D 看向鼠标。这只是头部和眼睛的粗略转向，不是精确的眼球追踪。

更自然的效果是：摄像头检测到你的脸，计算你在画面里的位置，Live2D 的眼睛就转向那个位置，眼球的移动幅度和方向与你的位置对应。

实现这个的关键是**虹膜追踪**——不只是检测脸在哪里，而是检测眼睛里的瞳孔在眼眶里的位置，然后把这个信息驱动到 `ParamEyeBallX` / `ParamEyeBallY` 参数上。

我们用 **MediaPipe FaceMesh** 做这件事。它能识别 478 个面部关键点，其中包括虹膜（瞳孔）的精确位置——这是普通面部检测库做不到的。

---

## 13.2 引入 MediaPipe

不需要安装任何东西，直接在 HTML 里用 CDN 引入：

```html
<script src="https://cdn.jsdelivr.net/npm/@mediapipe/face_mesh/face_mesh.js" crossorigin="anonymous"></script>
<script src="https://cdn.jsdelivr.net/npm/@mediapipe/camera_utils/camera_utils.js" crossorigin="anonymous"></script>
```

如果担心网络问题（比如国内访问 CDN 不稳定），也可以用 npm 把这两个包的文件下载下来放到 `libs/mediapipe/` 文件夹，改成本地路径。

在 `index.html` 里还需要一个隐藏的 `<video>` 元素，作为摄像头输入的载体：

```html
<video id="camera-feed" style="display:none" playsinline></video>
```

## 13.3 关键点编号

FaceMesh 提供 478 个关键点，带上虹膜的话是 478 个（需要 `refineLandmarks: true`）。

**虹膜关键点**：
- 左眼虹膜中心：点 468
- 右眼虹膜中心：点 473

**眼角关键点**（用来确定眼眶的范围，从而计算虹膜在眼眶内的相对位置）：
- 左眼：左角 33，右角 133
- 右眼：左角 362，右角 263

**头部定向**：鼻尖 1，左耳 234，右耳 454，额头 10，下巴 152

## 13.4 FaceTracker.js 的设计

新建 `frontend/FaceTracker.js`，封装所有摄像头和面部检测的逻辑，对外暴露几个简单的接口。

**初始化**：创建 `FaceMesh` 实例，设置 `refineLandmarks: true`（开启虹膜追踪，没有这个就检测不到 468 和 473 这两个虹膜关键点）。然后用 `Camera` 工具类启动摄像头，把每一帧传给 FaceMesh 处理。

**选最近的脸**：如果摄像头前有多个人，我们要跟踪最近的那个（通常是正在和 AI 说话的人）。"最近"用脸的大小来近似——边界框面积越大，人离摄像头越近。

```javascript
_selectNearestFace(faces) {
    let maxArea = 0, nearest = null;
    for (const face of faces) {
        const xs = face.map(p => p.x);
        const ys = face.map(p => p.y);
        const w = Math.max(...xs) - Math.min(...xs);
        const h = Math.max(...ys) - Math.min(...ys);
        const area = w * h;
        if (area > maxArea) { maxArea = area; nearest = face; }
    }
    return nearest;
}
```

**计算眼球位置**：对左眼和右眼分别计算虹膜在眼眶里的偏移，然后平均。

计算方式：虹膜中心减去眼眶左角，除以眼眶宽度，得到 0~1 的范围，再映射到 -1~1。两只眼平均，减少单眼误差。

```javascript
_calcEyePosition(landmarks) {
    // 左眼
    const lIris = landmarks[468];
    const lLeft = landmarks[33];
    const lRight = landmarks[133];
    const lWidth = lRight.x - lLeft.x;
    const lX = (lIris.x - lLeft.x) / lWidth * 2 - 1;

    // 右眼（坐标系镜像，注意方向）
    const rIris = landmarks[473];
    const rLeft = landmarks[362];
    const rRight = landmarks[263];
    const rWidth = rRight.x - rLeft.x;
    const rX = (rIris.x - rLeft.x) / rWidth * 2 - 1;

    return { x: (lX + rX) / 2, y: 0 };  // y 方向可以类似计算
}
```

**平滑处理**：每帧直接把计算结果设给 Live2D，眼球会抖动。用指数平滑（新值 = 旧值 × (1 - α) + 新值 × α）让运动柔顺：

```javascript
this._smoothedEye.x = this._smoothedEye.x * (1 - this._smoothing) + rawX * this._smoothing;
```

`_smoothing = 0.15` 是比较好的值——响应不太慢，也不会抖。

**没检测到脸时**：回退到鼠标跟随（第 9 章写好的 `enableMouseTracking`）。这样即使用户不面向摄像头，Live2D 也不会突然定住不动。

## 13.5 在 main.js 里启动追踪

初始化完 Live2D 之后，初始化 FaceTracker：

```javascript
const faceTracker = new FaceTracker();

faceTracker.onFacePosition = (x, y) => {
    // 把检测到的位置传给 Live2D
    live2d.model.focus(x, y);
    // 同时更新眼球参数
    live2d.setEyeBall(x, y);
};

faceTracker.onNoFace = () => {
    // 没检测到脸，回退到鼠标跟随
};

faceTracker.start();  // 启动摄像头
```

**`live2d.setEyeBall(x, y)`** 是在 `Live2DController.js` 里新增的方法，直接设置 `ParamEyeBallX` / `ParamEyeBallY` 参数，而不是依赖 FaceMesh 的 `focus()` 方法（那个是模糊的头部转向，不够精确）。

---

## 13.6 隐私说明

摄像头数据在本地处理，不会发送到任何服务器。MediaPipe 的模型在浏览器里运行（WebAssembly），所有计算都在用户设备上完成。

用户第一次打开页面时，浏览器会弹出摄像头权限请求。如果拒绝，就回退到鼠标跟随模式，功能照常，只是没有人脸追踪。

---

## 13.7 调试技巧

如果眼球追踪不准，打开 Console，在页面上加一个 debug canvas，把 FaceMesh 的关键点画出来，直接看哪些点检测到了、位置对不对。

```javascript
// 在 FaceTracker 的 onResults 回调里
if (results.multiFaceLandmarks) {
    console.log("虹膜左眼中心：", results.multiFaceLandmarks[0][468]);
}
```

> **试一下**：启动摄像头追踪后，慢慢左右移动头部，观察 Live2D 的眼睛有没有跟随。然后左右移动得快一点，看平滑程度是否合适。如果眼球反应太迟钝，把 `_smoothing` 调大（比如 0.3）；如果抖动，调小（0.08）。

---

## 本章小结

- MediaPipe FaceMesh + `refineLandmarks: true` 才能拿到虹膜关键点（468 / 473）
- 通过边界框面积大小选出最近的人脸
- 虹膜在眼眶内的相对位置（0~1）→ 映射到 -1~1 → 驱动 `ParamEyeBallX` / `ParamEyeBallY`
- 指数平滑（α ≈ 0.15）让眼球运动柔顺，不抖动
- 没检测到脸时回退鼠标跟随，保证体验连续
